# The JLLs whose product is already in $PREFIX — the "Termux ships it" universe.
#
# That is the only universe where the no-duplication rule can be applied at all: if the
# library is not there, the question "can the system satisfy the JLL?" has no answer other
# than no, and the item belongs in a different list (`pkg install`, or Yggdrasil).
#
# Selected on 2026-10-11 by listing `$PREFIX/lib/*.so*` on the device (1877 files) and
# keeping the JLLs whose declared product is among them.  FFTW_jll and libpng_jll are the
# two cases docs/14 already documents, and they are first on purpose: they must come back
# with the same verdicts, which makes this file a regression test for the tool as well.
#
# Run it with a scratch depot (see the header of classify-jll.jl) so the comparison is
# against the official artifacts and the downloads do not land in the user's depot.
